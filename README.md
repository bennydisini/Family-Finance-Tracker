# Family-Finance-Tracker
Nama Aplikasi : Rekap Keuangan Keluarga (Family Finance Tracker) <br>
Tujuan        : Memudahkan keluarga dalam mencatat, melacak, dan merekapitulasi arus kas (pemasukan & pengeluaran) dengan dashboard analitik sederhana dan laporan berkala (harian, mingguan, bulanan).<br>

# FITUR UTAMA : <br>
1. Dashboard Ringkasan: Menampilkan metrik utama seperti Saldo Saat Ini, Total Pemasukan, dan Total Pengeluaran secara real-time.<br>
2. Pencatatan Transaksi (CRUD): Fasilitas untuk menambah (Input), mengubah (Update), dan menghapus (Hapus) data pemasukan atau pengeluaran. <br>

Kategorisasi: Pengelompokan transaksi (misal: Gaji, Belanja Dapur, Tagihan, Hiburan, dll) untuk analisis yang lebih baik.<br>
Rekapitulasi Berkala: Tampilan laporan transaksi yang difilter berdasarkan Harian, Mingguan, atau Bulanan.<br>
Sistem Sesi (Anti-Logout): Pengguna tetap login meskipun halaman di-refresh, menggunakan localStorage.
